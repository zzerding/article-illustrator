# Design Specification — Article Illustrator

> 给文章配图的 Web 应用，基于 Pollinations BYOP + Cloudflare Pages

---

## 1. 产品定位

**一句话**：把一篇文章粘进来，选中任意段落，AI 立刻为它生成一张配图。

目标用户：独立博主、内容创作者、公众号编辑，需要快速为文章配图但不想逐段手写 prompt。

---

## 2. 用户旅程（Happy Path）

```
访问首页
  │
  ▼
[未授权] ──► 点击「用我的 Pollen 开始」
              │
              ▼
           Pollinations BYOP 授权页
           （用 GitHub 账号登录 + 确认授权）
              │
              ▼
           回调到应用（URL fragment 携带 sk_...）
              │
              ▼
[已授权] ──► 显示编辑器主界面
              │
              ▼
           粘贴 / 输入文章文本
              │
              ▼
           文章渲染成段落列表
           每段右侧有「🎨 配图」按钮
              │
              ▼
           点击某段「配图」
           → AI 分析该段落，生成 image prompt
           → 调用 Pollinations 图像 API
           → 图片展示在段落右侧 / 下方
              │
              ▼
           用户可点击图片下载，或重新生成
```

## 4. 核心交互细节

### 4.1 段落解析规则
- 按换行符（`\n\n` 或连续 `\n`）分割段落
- 过滤掉少于 20 字的段落（标题、空行等）
- 每段显示前 100 字 + 折叠展开

### 4.2 Prompt 生成策略
调用 Pollinations Text API（`openai` 模型）：

```
系统角色：你是专业的图像 prompt 工程师，擅长将文章段落转化为
          Stable Diffusion / Flux 图像生成 prompt。

用户输入：[段落原文] + [风格指令]

输出要求：纯英文 prompt，60 词以内，不含人名/版权内容，
          适合 Pollinations /v1/image 接口
```

### 4.3 图像生成
- 模型：`flux`（Pollinations 默认高质量模型）
- 尺寸：`1024x576`（16:9，适合文章配图）
- API：`https://image.pollinations.ai/prompt/{encoded_prompt}?model=flux&width=1024&height=576&nologo=true`
- 鉴权：在请求 header 中带 `Authorization: Bearer sk_...`

### 4.4 加载态
- 点击「配图」后按钮变为加载动画
- 右侧图片区域显示骨架屏（灰色占位）
- 生成完成后淡入图片

### 4.5 重新生成
- 每张图片下方提供「↺ 重新生成」
- 点击后保持相同段落+风格，重新请求

## 5. 视觉设计方向

**风格定位**：editorial / 杂志排版风，克制优雅，强调内容本身。

| 设计元素 | 决策 |
|---------|------|
| 配色 | 近白底 `#FAFAF8` + 墨黑 `#1A1A1A` + 单一强调色（暖橙 `#E8622A`） |
| 字体 | 标题：`Playfair Display`（衬线，文学感）；正文：`Source Han Sans`（中文优先） |
| 布局 | 两栏（文字左 60% / 图片右 40%），移动端折叠为单栏 |
| 段落卡片 | 无边框，靠间距区隔，悬停时左边出现橙色细线 |
| 按钮 | 小而精，纯文字+下划线风格，避免大色块按钮 |
| 图片 | 带轻微投影，圆角 4px，生成时有淡入动画 |

## 6. 错误处理

| 场景 | 处理方式 |
|------|---------|
| BYOP 授权被拒 | 显示友好提示，提供「重新授权」按钮 |
| `sk_...` 过期（7天） | API 返回 401 时，清除本地 key，提示重新授权 |
| Pollen 余额不足 | 显示提示「你的 Pollen 不足，请前往 Pollinations 充值」+链接 |
| 图片生成超时 | 30s 超时后显示「生成失败，请重试」 |
| 文章过长（>50 段） | 提示「已截取前 50 段进行解析」 |

---

## 7. 数据与隐私

- **零后端**：纯静态 SPA，部署在 Cloudflare Pages，无服务端
- **`sk_...` 存储**：仅存于 `sessionStorage`，关闭标签页即失效；不写 `localStorage`
- **文章内容**：只在浏览器内存中处理，不发送到任何第三方（除 Pollinations API）
- **用户信息**：调用 `/api/device/userinfo` 获取用户名用于顶栏展示，不持久化

---

## 8. 响应式断点

| 断点 | 布局变化 |
|------|---------|
| `≥ 1024px` | 两栏布局（文字左 / 图片右） |
| `768px – 1023px` | 两栏压缩，图片宽度 35% |
| `< 768px` | 单栏，图片在段落文字下方 |
